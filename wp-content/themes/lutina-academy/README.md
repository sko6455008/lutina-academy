# 固定ページの編集

## Figma SP版LP（2026-10-25）

トップページをFigma「占いLP / SP」（2022:8）の原稿・配色を基にしたレスポンシブLPへ変更しました。FVは支給された完成画像、それ以降のセクションは写真・イラストを組み合わせたHTML/CSSです。

- **固定ページ → トップページ**：セクションを開いて文章・画像を編集。「料金」で検索すると受講回数・時間・料金・カリキュラムが見つかります。
- **共通：相談ボタン**：「無料相談する」と `https://lin.ee/Ub7dXw5` を固定ボタンを含む6か所で共有します。
- **お試し体験**：講座カリキュラム内に90分／33,000円の案内と専用の相談ボタンを追加しています。文言は「無料相談する」、リンク先は共通ボタンと同じLINEです。体験の文章・料金・リンクは個別に編集できます。
- **LPのFAQ**：タイトルが質問、本文が回答。「順序」の小さいものから表示します。下書き・ゴミ箱は表示されません。旧「Q&A」8件はゴミ箱へ移動し、管理メニューから非表示にしました。旧Q&Aの自動登録も停止しています。ゴミ箱保持期間内は `/wp-admin/edit.php?post_status=trash&post_type=qa` から復元できます。
- 写真はメディアライブラリから変更できます。文章・画像の説明も編集できます。
- 保存・プレビュー・自動保存・変更履歴にはWordPress標準の仕組みを使用しています。

Figma原稿のカリキュラム2段目・3段目はいずれも「4〜5回／応用リーディングを学ぶ」のため、そのまま転記しています。CTA以外の説明会表記も原稿に合わせています。

### ファイルと素材

- `templates/landing.html`、`landing.css`：LPのマークアップとスタイル。
- `landing-motion.css`・`landing-motion.js`：セクション見出し・写真・カードのスクロール表示（各要素1回）、固定CTAの3.2秒周期の拡大縮小、ボタンのホバー動作。固定CTAはホバー・フォーカス中に停止します。端末の「視差効果を減らす」設定ではアニメーションを無効化し、JavaScriptが無効でも本文は表示します。受講の流れのCTAは全画面幅で中央揃えです。
- `landing-desktop.css`：900px以上のPC専用レイアウト。本文幅は最大1240〜1280px、本文は主に18px、教育方針は2列、受講の流れ・受講生の声は3列、カリキュラムは見出しと内容の横組みです。FAQは1列を維持します。SPのスタイルとは分離しています。
- `landing-refinements.css`：PC・SPのFV画像と相談リンクの配置、教育方針2・4の写真、PCの悩む女性イラストの配置。FVは支給画像 `assets/images/fv-pc-v7.png`（900px以上）・`fv-sp-v7.png`（900px未満）を使用します。「01 メインビジュアル」からPC/SP画像、読み上げ用の見出し・説明を変更できます。画像に描かれた文字を変更する場合は画像自体を差し替えてください。
- `assets/images/lp-policy2-v4.png`・`lp-policy4-v4.png`：内蔵image_genで制作した教育方針のイメージ写真。管理画面の「05 教育方針」から画像・説明・キャプションを編集できます。生成プロンプトは `assets/images/lp-v4-generation-prompts.json` に保存しています。
- `inc/landing-fields.json`：初期原稿・画像URL・編集定義。
- `inc/landing.php`：新LPとFAQの初回導入。導入後に再実行しても編集内容を初期化しません。
- `inc/landing-faq.json`：FigmaのFAQ初期原稿。導入後の変更は管理画面から行います。
- `header-landing.php`：LPと特商法ページで共通の書体・ヘッダー設定を使用します。
- `legal.css`・`templates/legal.html`：特商法ページをLPと同じ配色・装飾に統一。体験と本講座の名称・時間・料金は、トップページに保存した値と連動します。
- `assets/images/lp-*.webp`：添付されたLP画像を基準に、内蔵image_genで写真・モノクロ線画・星座柄・大理石・FAQ背景を再生成しました。今回追加した16素材の元PNGも同フォルダーに保存しています。プロンプトは `lp-v2-generation-prompts.json` と `lp-v2-more-prompts.json` に記録しています。人物写真はイメージ素材で、講師プロフィールは実際の既存素材 `rumika.webp` を使用しています。
- FVはPC・SPとも画面幅いっぱいに元画像の縦横比を保って表示し、高さ制限やトリミングを行いません。新版FVには画像内ボタンがないため、透明なリンク領域は配置しません。画面下の固定CTAも維持します。FAQはPCでも1列です。本文末尾には固定CTAに隠れない余白を確保しています。
- 見出しはShippori Mincho、本文はNoto Sans JPを使用します。元デザインは画像のためフォント名は取得できず、文字の形状を基準に近い書体を選定しています。
- お悩み・方針・講師・FAQの背景画像も、固定ページの各セクションから変更できます。

旧トップページ本文はWordPressの変更履歴と `lutina_academy_pre_landing_backup` オプションに保存しています。テーマだけを戻してもページ本文は戻らないため、旧版へ戻す場合は本文の復元も行ってください。

Gitにはテーマのコード・初期原稿・素材を保存しています。管理画面で保存した本文やFAQ、旧Q&Aのゴミ箱への移動状態はWordPressのデータベースに保存されるため、別環境へ反映する際はDBも移行してください。

### 検証

`tests/verify-landing.php` はWordPressのREST保存、画像・料金・文章の反映、プレビュー、FAQの追加・並び順・削除、権限、HTMLの無害化を検証します。専用の一時テストページとFAQのみ作成・削除します。
`tests/verify-editable-pages.php` は表記ページを含む従来の保存・変更履歴機能を検証します。
`tests/preview.html` は同じLPを390pxと1440pxで並べる開発用確認ページです。

以下は旧LP・表記ページの編集機能の説明です。

WordPress管理画面の「固定ページ」から、次の2ページを編集できます。

- **トップページ**：セクションを開き、文章・画像・リンクを変更します。「編集項目を検索」で料金・講師・住所などの項目を探せます。画像は「画像を選択・変更」からメディアライブラリで選択できます。
- **特定商取引法に基づく表記**：事業者名・運営責任者・住所・営業時間・事業内容・料金リンク・メールアドレス・戻るボタンの文字を変更できます。ページ見出しは固定ページのタイトルに連動します。

編集後は右上の「保存」で反映します。WordPress標準のプレビュー、自動保存、変更履歴に対応しています。初期状態も変更履歴に保存します。配置・色・装飾はテーマ側で維持します。

Q&Aの質問と回答は、引き続き管理画面の「Q&A」で編集します。トップページのQ&A編集欄にも管理画面へのリンクがあります。

## テーマの導入・更新

追加ファイルを含めてテーマ全体を配置してください。初回アクセス時にトップページを作成してホームページに設定し、本文が空の表記ページには初期内容を登録します。すでに入力済みの本文は上書きしません。2回目以降のアクセスで編集内容が初期化されることもありません。

掲載内容はWordPressのデータベースに保存されます。テーマファイルのGit管理とは別に、通常のWordPressバックアップ・移行の対象になります。

## 実装と検証

- `inc/page-fields.json`：編集項目と初期値。
- `templates/home.html`・`templates/legal.html`：レイアウト。項目の値は置換時に種類に応じてエスケープします。
- `inc/editable-pages.php`：ページの初期設定、動的ブロックの登録・描画。
- `page-editor.js`・`page-editor.css`：管理画面の編集欄。
- `template-parts/faq.php`：既存のQ&A投稿の表示。

WP-CLIがある環境では、以下で保存・自動保存・変更履歴・アクセス権・表示の検証を実行できます。専用の非公開テストページを作り、検証後にそのページのみ削除します。

```sh
wp eval-file wp-content/themes/lutina-academy/tests/verify-editable-pages.php
```

または、WordPressのDBへ接続できるPHP CLIで同ファイルを実行してください。
