# 固定ページの編集

WordPress管理画面の「固定ページ」から、次の2ページを編集できます。

- **トップページ**：セクションを開き、文章・画像・リンクを変更します。「編集項目を検索」で料金・講師・住所などの項目を探せます。画像は「画像を選択・変更」からメディアライブラリで選択できます。
- **特定商取引法に基づく表記**：事業者名・運営責任者・住所・営業時間・事業内容・料金リンク・メールアドレス・戻るボタンの文字を変更できます。ページ見出しは固定ページのタイトルに連動します。

編集後は右上の「保存」で反映します。WordPress標準のプレビュー、自動保存、変更履歴に対応しています。初期状態も変更履歴に保存します。配置・色・装飾はテーマ側で維持します。

Q&Aの質問と回答は、引き続き管理画面の「Q&A」で編集します。トップページのQ&A編集欄にも管理画面へのリンクがあります。

## テーマの導入・更新

追加ファイルを含めてテーマ全体を配置してください。初回アクセス時にトップページを作成してホームページに設定し、本文が空の表記ページには初期内容を登録します。すでに入力済みの本文は上書きしません。2回目以降のアクセスで編集内容が初期化されることもありません。

掲載内容はWordPressのデータベースに保存されます。テーマファイルのGit管理とは別に、通常のWordPressバックアップ・移行の対象になります。

## 実装と検証

- `inc/page-fields.json`：編集項目と初期値。
- `templates/home.html`・`templates/legal.html`：レイアウト。項目の値は置換時に種類に応じてエスケープします。
- `inc/editable-pages.php`：ページの初期設定、動的ブロックの登録・描画。
- `page-editor.js`・`page-editor.css`：管理画面の編集欄。
- `template-parts/faq.php`：既存のQ&A投稿の表示。

WP-CLIがある環境では、以下で保存・自動保存・変更履歴・アクセス権・表示の検証を実行できます。専用の非公開テストページを作り、検証後にそのページのみ削除します。

```sh
wp eval-file wp-content/themes/lutina-academy/tests/verify-editable-pages.php
```

または、WordPressのDBへ接続できるPHP CLIで同ファイルを実行してください。
